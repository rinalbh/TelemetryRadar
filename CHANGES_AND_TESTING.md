# TelemetryRadar — Analytics

Дата: 25 октября 2026. Репозиторий: `C:\Users\nasty\telemetryradar`. Фронтенд: `C:\Users\nasty\telemetryradar\ui`.

## Что сделано

- Первый экран Analytics по предоставленному референсу: голубой фон, белые панели, общий график и семь приложений с иконками и полосами трафика.
- Svelte 5.57.2, SvelteKit 3.1.0, TypeScript 6.0.3 (трактовка указанного «6.03»), Vite 8.3.5, Paraglide JS 2.29.1. Воспроизводимые версии зафиксированы в `package-lock.json`.
- Только английский язык. Переключателя, русского словаря и выбора языка через настройки браузера нет. Paraglide оставлен с единственной локалью `en` и стратегией `baseLocale`.
- Десктопная компоновка с минимальной шириной 960 px. Мобильной версии нет. При меньшей ширине окно прокручивается горизонтально. Для комфортного просмотра рекомендуется 1280×900 и больше.
- Начальное состояние берётся из `src/lib/telemetry/mock-traffic.json`. Каждые 5000 мс создаётся следующий JSON-снимок: общий график, текущие скорости, объёмы и все полосы приложений обновляются вместе.
- Верхний график показывает последние 5 минут: 61 точка с шагом 5 секунд. Входящий трафик расположен над нулём, исходящий — под нулём; обе скорости положительные. Масштаб автоматически увеличивается при необходимости. Время отображается в МСК.
- Скорости измеряются в KB/s, накопленные объёмы — в KB/MB; 1 KB = 1024 байта. Полосы приложений используют общую шкалу накопленного объёма. Цвета: бирюзовый — input, синий — output.
- Program отсортирован по накопленному объёму Input + Output по убыванию. Сортировка пересчитывается на каждом снимке, исходный JSON при этом не изменяется. При равных объёмах порядок определяется стабильным ID процесса.
- Наведение на график показывает время и обе скорости, наведение на полосу — объёмы входящего и исходящего трафика.
- Кнопка Pause updates замораживает отображаемый снимок. Источник продолжает генерировать данные; Resume updates сразу показывает последний снимок. При перезагрузке начинается новая демонстрационная сессия.
- `TelemetrySource` отделяет источник данных от интерфейса; при уничтожении компонента интервал очищается.
- Статическая SPA-сборка в `build/` без обязательного Node-сервера при запуске приложения — основа для последующего подключения Tauri.

Это первый экран с демонстрационными данными. Захват реального трафика, агент, анализ конфиденциальных данных и оболочка Tauri пока не реализованы.

## Как проверить готовую сборку

Из папки `ui`, после `npm run build` (выходные файлы находятся в `ui/build/` относительно корня репозитория):

```powershell
npm run preview -- --port 4173
```

Откройте `http://127.0.0.1:4173/`. Проверяйте в активной вкладке: фоновые вкладки браузер может обновлять реже.

1. Видны Analytics, Traffic rate и Program, семь приложений с локальными иконками; фон и цвета соответствуют референсу.
2. Нет переключателя языка. Интерфейс английский, даже если основной язык браузера русский.
3. Подождите 10–15 секунд: линия и заливки графика меняются, растут полосы и объёмы приложений, меняется `Updated`. Из-за округления крупный объём в MB может выглядеть одинаково несколько тиков; в строке rapportd изменение заметно быстрее.
4. Нажмите кнопку с индикатором Live. Появится Updates paused. За следующие 10 секунд график, полосы, объёмы и время Updated остаются неизменными.
5. Нажмите ту же кнопку: сразу появится последний снимок и возобновятся обновления.
6. Наведите указатель на график и полосы: появятся подсказки с числовыми значениями.
7. Проверьте ширины десктопного окна 960, 1280 и 1586 px. Строки сохраняют горизонтальную структуру. При ширине менее 960 px ожидается горизонтальная прокрутка, а не мобильная раскладка.
8. Перезагрузите страницу: демо начинается заново. Проверьте консоль браузера — ошибок приложения быть не должно.
9. Сразу после перезагрузки порядок Program: Google Chrome Helper → Slack Helper → thunderbird → zoom.us → Unknown process → Telegram → rapportd. После каждого обновления значения справа остаются отсортированы по убыванию общего объёма; при сравнении KB и MB учитывайте единицы.

### Точная проверка синхронности в DevTools

При включённых обновлениях выполните в консоли браузера:

```js
const readRadar = () => ({
  sequences: [...document.querySelectorAll('[data-sequence]')]
    .map(el => Number(el.dataset.sequence)),
  path: document.querySelector('path[stroke="#00dce6"]')?.getAttribute('d'),
  widths: [...document.querySelectorAll('.bar-total')].map(el => el.style.width)
});
const before = readRadar();
setTimeout(() => {
  const after = readRadar();
  console.table({
    newSnapshot: after.sequences[0] > before.sequences[0],
    synchronizedPanels: after.sequences[0] === after.sequences[1],
    chartChanged: after.path !== before.path,
    allBarsChanged: after.widths.every((width, i) => width !== before.widths[i])
  });
}, 5600);
```

Все четыре значения должны быть `true`. На паузе `newSnapshot`, `chartChanged`, `allBarsChanged` должны быть `false`, а `synchronizedPanels` — `true`.

## Как заменить моки агентом / Tauri

1. Реализуйте `TelemetrySource.subscribe(listener)` из `types.ts` на событиях агента. Метод возвращает функцию отписки.
2. Получайте полный JSON-снимок и проверяйте его через `parseSnapshot(json)` до передачи в UI. Повреждённый пакет следует обработать в адаптере источника: оставить предыдущий снимок и сообщить о сбое соединения.
3. В `+page.svelte` замените вызов `createMockSource()` своим источником. Общий график и список приложений уже используют единый объект `snapshot`.
4. Передавайте стабильные `applications[].id`, имя, иконку, накопленные байты и текущие скорости. Имена не зашиты в разметке. Иконки сейчас принимаются из `/icons/<name>.svg` или как base64 PNG/JPEG/WebP; поддержку Tauri asset URL нужно добавить при интеграции.
5. `history` содержит 2–61 строго упорядоченную точку, время — Unix timestamp в миллисекундах, скорости — байты/секунду. Последнее время истории совпадает со временем снимка. Для согласованности скорости последней точки должны быть суммой скоростей приложений. Пример полного пакета — `mock-traffic.json`.
6. Для Tauri используйте `devUrl: http://127.0.0.1:5173`, `frontendDist: ../ui/build` относительно будущей корневой папки `src-tauri`, `beforeDevCommand: npm --prefix ui run dev`, `beforeBuildCommand: npm --prefix ui run build`. Рекомендуемая минимальная ширина окна — 960 px. Сам `src-tauri` в этом этапе не создавался.
